## English

End-to-end pipeline Agent Skill for **AI-generated promotional videos**. Covers the full 4-phase workflow from model research to shot-by-shot prompts, designed for tools like doubao-seedance, Sora, Kling, Runway, and HeyGen.

### What it does

1. **Model research** — survey video generation models, write capability reports
2. **Marketing copy** — positioning, value props, differentiation, CTAs
3. **Voiceover script** — spoken-style script for digital human or narrator, multi-length versions per channel
4. **Shot-by-shot prompts** — concrete video generation prompts following each model's official writing conventions

### When to trigger

- Make a promotional/brand/marketing video using AI tools
- Research AI video generation models
- Write voiceover/narration scripts
- Write shot-by-shot prompts for AI video models
- Plan an end-to-end AI video production

### Design principle

A **framework**, not a template tied to any vertical. Adapts to the project's actual audience, brand voice, and product category — examples illustrate structure, not content to copy.

### Project structure

```text
ai-promo-video/
├── SKILL.md                           Routing rules and workflow
├── assets/
│   ├── copy-template.md               Marketing copy template
│   ├── segments-template.json         Shot segments JSON schema
│   └── voiceover-template.md          Voiceover script template
└── references/
    ├── research-template.md           Model research report template
    ├── seedance-guide.md              Doubao-seedance prompt guide
    └── shot-prompt-template.md        Shot-by-shot prompt template
```

## 中文

端到端 Agent Skill，用于 **AI 生成的宣传/品牌视频**。覆盖从模型调研到分镜提示词的完整 4 阶段工作流，适配豆包 seedance、Sora、Kling、Runway、HeyGen 等工具。

### 核心功能

1. **模型调研** — 调研视频生成模型，输出能力报告
2. **营销文案** — 定位、价值主张、差异化、CTA
3. **口播脚本** — 数字人/旁白口语化脚本，多长度版本适配不同渠道
4. **分镜提示词** — 按各模型官方写作规范生成具体视频生成提示词

### 触发场景

- 用 AI 工具做宣传/品牌/营销视频
- 调研 AI 视频生成模型
- 写视频口播/旁白脚本
- 写 AI 视频模型的分镜提示词
- 规划端到端 AI 视频制作流程

### 设计原则

**框架而非模板**——不绑定任何特定行业。适配项目实际的受众、品牌调性和产品类别；示例用于说明结构，不是照抄的内容。
